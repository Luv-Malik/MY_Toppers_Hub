## ✨ Features

- 🌌 **Dark Glassmorphic UI:** Smooth backdrop-filters, animated canvas sparkle effects, and crisp typography.
- 🔍 **Instant Smart Search:** Real-time modal search with alias support (e.g., search `M1`, `OS`, `FLAT`, `DSA`, or `AI`).
- 📚 **Semester-Wise Catalog:** Organized navigation from **Semester 1 through 8** covering core CSE subjects.
- 📄 **Unit-Wise PDF Access:** Direct unit-level PDF downloads with fallback prompts for missing resources.
- 💡 **Dynamic Daily Motivation:** Rotating quote widget to keep students inspired during late-night study sessions.
- 📱 **Fully Responsive & Accessible:** Optimized for mobile, desktop, and keyboard navigation (`Tab` / `Enter` support).

---

## 🛠️ Tech Stack

- **HTML5 & CSS3:** Custom CSS (Modern Glassmorphism, CSS Animations, Flexbox & CSS Grid)
- **JavaScript (ES6+):** Pure Vanilla JS for DOM manipulation, search indexing, dynamic modals, and quotes rotation.
- **UI Design System:** Dark Theme (`#05070a`) with Cyan Highlights (`#06b6d4`).
