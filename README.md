# 🎓 Toppers Notes Hub
### *Computer Science & Engineering Exam Portal*

> A modern, glassmorphic web application for CSE students to effortlessly clear mid-terms & end-sem exams with unit-wise handcrafted toppers' notes.

---

[🌐 Live Demo](https://luv-malik.github.io/MY_Toppers_Hub/) • [📌 Report Issue](https://github.com/luv-malik/MY_Toppers_Hub/issues) • [📜 License (MIT)](LICENSE)

---

### ✨ Key Features

* **🌌 Dark Glassmorphic UI:** Smooth backdrop-filters, animated sparkle effects, and crisp typography.
* **🔍 Instant Smart Search:** Real-time modal search with alias support (`M1`, `OS`, `FLAT`, `DSA`, `AI`).
* **📚 Semester-Wise Catalog:** Organized navigation from **Semester 1 through 8** covering core CSE subjects.
* **📄 Unit-Wise PDF Access:** Direct unit-level PDF downloads with fallback prompts for missing resources.
* **💡 Dynamic Daily Motivation:** Rotating quote widget to keep students inspired during late-night study sessions.
* **📱 Fully Responsive:** Optimized for mobile, desktop, and keyboard navigation (`Tab` / `Enter`).

---

### 🛠️ Tech Stack

* **Frontend:** HTML5, Modern CSS3 (Glassmorphism, CSS Animations, Grid)
* **Scripting:** Pure Vanilla JS (DOM Manipulation, Real-time Search Indexing, Modals)
* **Theme:** Dark Aesthetics (`#05070a`) with Cyan Highlights (`#06b6d4`)
